# 사립미술관·기업 문화공간 조사

확인일: 2026-10-18. `data/private-museums.json` 13곳, 재생성 스크립트 `scripts/build-private-catalog.mjs`.

각 항목에 공개 출처, 예약 안내, 대표번호, 확인 가능한 이메일을 보관한다. 관람·단체 예약의 실제 잔여석은 확인하지 않았으며 상태는 모두 문의 필요다. 기획전별 가격을 시설의 영구 가격으로 예산 계산에 적용하지 않는다. 일반 단체 조건을 교육청 협약으로 표기하지 않는다.

- 리움·호암: 공식 방문 안내의 단체 예약 및 할인 없음 안내. 호암은 용인으로 서울 밖 필터에 포함.
- 간송: 서울관 공식 안내. 대구관과 구분하며 전시 기간별 공개 여부 확인 필요.
- 사비나·환기: 공식 관람 안내의 일반 단체 조건, 교육 연락처.
- 성곡: 서울문화재단 SPAC 시설 안내로 연락처 확인. 현재 전시 조건 별도 문의.
- 대림·디뮤지엄: 공식 통합 홈페이지 및 https://m.daelimmuseum.org/ 연락처, 서울관광재단 디뮤지엄 안내의 현재 주소 확인.
- 아모레퍼시픽: 공식 관람 안내와 메인 페이지. 확인일 기획전 예약·학생 요금 구분.
- 롯데뮤지엄: 공식 관람 안내. 기획전 요금에 적용 전시 기간 명시.
- 코리아나: 문화포털의 2026년 봄 전시는 종료된 근거 자료임을 명시. 현재 전시·단체 조건은 문의.
- 송은: 공식 홈페이지의 직전 전시 종료일과 다음 전시 예정일을 함께 표기.
- 광야 서울: SMTOWN &STORE 공식 FAQ의 현재 오프라인 매장·전화 확인. 학교 교육 프로그램 확인되지 않음, 매장 중심 공간으로 설명. 옛 코엑스 아티움 운영 종료 참고: https://www.hankyung.com/article/202005207478H

예약 보조 링크는 예약 URL의 origin(없으면 출처 origin)으로 연결한다. 외부 예약 페이지를 자동 조회하거나 재시도하지 않는다. 문의 전화는 원문을 표시하면서 첫 번째 유효한 번호만 전화 링크에 사용하여 복수 번호가 연결되는 오류를 방지한다. 전화번호가 없으면 임의 번호를 추가하지 않고 미등록 안내를 제공한다.
