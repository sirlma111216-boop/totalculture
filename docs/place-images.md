# 이미지 표시와 출처 — 2026-10-18

- 3×2 정사각형 일러스트 아틀라스를 컨테이너 비율대로 늘리던 동작을 수정했다. 각 타일은 정사각형을 유지하고 작은 카드에서만 필요한 부분을 자른다. 상세의 일러스트는 최대 420px 정사각형으로 표시한다.
- 실제 사진·포스터는 object-fit:contain으로 원본 비율과 전체 내용을 보존한다. 불러오기 실패 시 일러스트 및 안내로 대체한다.
- 서울문화포털 MAIN_IMG, 공공서비스예약 IMGURL, KOPIS poster를 저장한다. 이미지 URL·출처·설명은 백업과 직접 수정에서도 유지한다. 서버 캐시 버전을 갱신했다.
- 기존 등록기관의 공식 페이지를 조사하고 이름·설명으로 대응이 확인된 23개 기관·공원의 사진을 data/place-images.json에 연결했다. 동일 브랜드 로고·기관 공통 배너·다른 지점 이미지는 대표 사진으로 임의 지정하지 않았다. 확인되지 않은 기관은 일러스트를 유지한다.
- 원본 이미지는 재배포하지 않고 공식 URL을 표시하며 상세에 출처 링크를 제공한다. 사진의 촬영 시점은 현재 운영 상태를 보증하지 않는다. 출처에 표시된 이용 조건은 원 출처에서 확인할 수 있다.
- 조사 중 한성백제박물관의 2026년 하반기 전시실 공사 공지를 발견하여 시설 설명에도 반영했다.
