# 요청 이력 대조 및 미반영 수정 — 2026-10-18

이 대화의 최초 제작 요청과 이후 추가 요청을 실제 앱의 자료 구성·화면·테스트와 대조했다. ‘서울의 모든 시설’이나 ‘모든 기관의 실시간 예약’을 확보했다는 뜻은 아니다. 아래의 제한과 승인 대기 항목을 완료로 포장하지 않는다.

## 이번에 발견하고 수정한 누락

- `public-institutions.json`과 생성 스크립트가 미추적 파일로 남아 있었고 앱 데이터에 연결되지 않았다. 기존 13건을 재검증하고 글로벌지식협력단지 학교 경제교육 1건을 더해 14건을 실제 자료에 연결했다.
- 글로벌지식협력단지: 전시·해설 / 학교 교육 / 대관을 별도 항목으로 연결. 공식 무료 관람·대관, 인원 협의, 전화·이메일을 구분했다.
- 홍릉숲: 자유탐방과 2026 숲해설을 분리. 단체 10명 이상 전화 협의·공문, 운영 종료일 2026-11-29를 반영했다.
- 외교사료관: 견학 전용 연락처 02-3497-8716, 15명 이상 비영리 학교 학급, 증빙 조건으로 갱신했다.
- 국립중앙도서관: 실감체험과 일반 시설견학 예약이 다르다는 안내를 추가했다.
- 국립수목원 교육: 2021년 과거 안내 링크를 현재 교육관리시스템으로 교체했다. 과거 요금·일정을 현재 조건으로 사용하지 않는다.
- 지도 검색창의 ‘출발하는 학교’를 ‘검색 기준 위치’로 통일했다.
- 공원 상세의 관련 프로그램에도 종료 행사 제외 조건을 적용했다.
- 설정의 오래된 ‘모든 시설 이미지는 일러스트’ 문구를 실제 사진·로고 정책으로 수정했다.
- 자료 구성은 `seed-catalog.mjs`로 공유해 테스트가 앱의 실제 등록 자료를 직접 읽는다. 모든 `data/*.json`의 장소 목록이 앱에 포함됐는지 검사한다.

## 외부 조건이 필요한 항목

1. **공유누리**: 사용자가 인증키 승인 대기 중이라고 확인했다. `ESHARE_API_KEY` Production Secret 등록·재배포 이후 실제 응답 형식과 수신 범위 검증이 필요하다. 공급자가 제공하지 않는 연락처·요금·잔여석은 추정하지 않는다. 체육시설 목록을 청소년센터 전수 목록으로 표시하지 않는다.
2. **앱 내부 대중교통 경로**: 앱 내 경로 화면과 ODsay Web 연동을 구현했다. ODSAY_WEB_API_KEY 및 허용 URI 등록이 필요하며 실제 서비스 응답 검증은 발급 후 진행한다. 실시간 도착정보가 아닌 예상 경로다.
3. **자료 범위**: 67개 영화관·11개 대학 등 조사 목록과 외부 API 수록 자료의 합집합이다. 모든 기관·프로그램·공단 시설의 전수 수록이나 실시간 이용 가능 여부를 보장하지 않는다.
